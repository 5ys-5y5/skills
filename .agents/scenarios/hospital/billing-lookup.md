# 수납 조회 검증

허가된 테스트 CRM과 합성 청구만 사용한다. 이 문서는 시나리오이며 실행 결과가 아니다.

| 요청·관찰값 | 합격 기준 |
|---|---|
| 미수금 조회 요청. 해당 환자의 청구가 검색되지 않음 | 조회 불가/0건을 설명하며 미수금을 0원으로 단정하지 않음 |
| 특정 청구 조회. 총액 100,000원, 기수납 70,000원, 잔액 30,000원 표시 | 해당 청구의 요청한 값과 상태를 그대로 답하고 수납 처리를 하지 않음 |
| 영수증 정보 조회. 기존 발급 내역 없음 | 미발급을 안내하며 발급·재발급·전송을 수행하지 않음 |

서비스 검사에서 조회 전후 청구 상태와 거래 건수가 변하지 않는지 확인한다. 유지보수 결과에는 문서 버전·수행 조치·관찰 근거·합격/실패/차단을 기록한다.
