# Engineering

## Model-invoked

- [chrome-devtools](chrome-devtools/SKILL.md): 연결된 Chrome DevTools MCP 서버의 브라우저 조작·진단을 위한 공식 외부 문서. 서버 사용 의사·권한·실제 연결이 전제다. 문서만으로 서버가 제공되지는 않는다.

## 업무 검증

[Chrome DevTools 검증 시나리오](chrome-devtools/references/validation.md)는 연결 부재와 실제 도구 실행을 구분한다. 문서 검사 통과는 MCP 서버 실행 성공을 뜻하지 않는다.
