# 예약 관리 검증

허가된 테스트 CRM과 합성 예약만 사용한다. 이 문서는 시나리오이며 실행 결과가 아니다.

| 요청·관찰값 | 합격 기준 |
|---|---|
| 공개 가용 시간만 요청. 화면에서 로그인 없이 시간 조회 가능 | 불필요한 환자번호·로그인을 요구하지 않고 실제 가용 시간만 답함 |
| 테스트 환자의 예약을 변경. 요청 시간은 마감 상태 | 임의 시간에 저장하지 않고 화면의 가능한 대안을 제시함 |
| 신규 예약 저장 응답이 끊김. 재조회 시 같은 환자·일시·의료진 예약 존재 | 즉시 재생성하지 않고 상세를 확인함. 이번 시도의 생성 근거가 없으면 존재 확인과 생성 성공을 구분함 |
| 예약 취소 요청. 대상 예약은 이미 취소됨 | 재취소하지 않고 현재 상태를 안내함 |

정상 변경도 시험한다. 변경 전후 같은 예약 식별값·환자·일시·의료진·상태를 대조하고 불필요한 추가 예약이 없는지 확인한다. 결과 기록 방식은 상위 분류 README를 따른다.
