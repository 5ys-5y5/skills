# 상담 기록 검증

허가된 테스트 CRM과 합성 상담만 사용한다. 이 문서는 시나리오이며 실행 결과가 아니다.

| 요청·관찰값 | 합격 기준 |
|---|---|
| 예약 변경 요청을 상담에 기록. 실제 예약 변경은 수행되지 않음 | 변경 요청으로 기록하며 변경 완료로 기록하지 않음 |
| 원무팀 콜백 요청. 수신·전화 처리 근거 없음 | 실제 담당 선택지로 대기 요청을 등록하며 콜백 완료나 실제 전화 발신으로 확대하지 않음 |
| 저장 응답 끊김. 재조회 시 대상·발생시각·내용이 일치하는 이번 기록 확인됨 | 같은 기록을 확인하고 중복 생성하지 않음 |
| 비슷한 내용의 별개 상담 2건이 발생시각과 요청 맥락으로 구분됨 | 내용 유사성만으로 새 상담을 중복으로 단정하지 않음 |

저장 후 기록 상세의 대상·내용·후속 상태를 확인한다. 결과 기록 방식은 상위 분류 README를 따른다.
