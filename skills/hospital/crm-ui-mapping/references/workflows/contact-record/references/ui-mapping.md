# 업무 항목과 화면 요소 대응

현재 접속한 CRM에서 아래 항목 중 요청 업무에 필요한 것을 실제 요소에 매핑한다. 고정 XPath나 특정 CRM의 화면 이름을 전제하지 않는다. 이 표는 업무 의미 정의이며 소비 서비스의 설정 키나 API 규격이 아니다.

| 업무 항목 | 의미와 범위 | 허용 역할 |
|---|---|---|
| 대상·기록 식별값 | 상담 대상 연결값과 기존 기록 상세의 식별값 | 읽기/선택 |
| 상담 내용·조치·결과 | 상담 편집 영역의 기록 입력란. 검색 입력·예약 메모와 구분 | 입력 |
| 담당·기한·연락 방법 | 실제 콜백 요청 영역의 선택지와 입력란 | 입력/선택 |
| 콜백 상태 | 요청 대기와 실제 처리 완료를 구분 | 읽기/선택 |
| 저장·저장 후 상세 | 상담 편집 영역의 실행 요소와 같은 기록의 상세 | 실행/읽기 |

각 항목에 실제 페이지/상세 영역, 소속 대상의 식별 기준, profile에 등록된 XPath, 읽기·입력·실행 역할, 판단 근거를 연결해 매핑을 표현한다. 재사용할 식별 방법과 실제 환자 기록은 구분하며 환자 정보와 인증 정보를 이 저장소에 저장하지 않는다.

XPath가 유일한 요소를 반환해도 의미 확인은 별도로 필요하다. 연결된 레이블·접근성 이름·열 제목·입력 유형·상위 영역과 대상 상세 식별값을 대조한다. 읽기용 금액 표시, 검색 필터, 실제 기록 입력란을 구분한다. 위치 번호나 비슷한 이름만으로 역할을 확정하지 않는다.

입력은 요청된 저장 대상의 편집 요소로 확인된 경우에만 한다. 필터 입력을 기록 저장으로 오인하지 않는다. 매핑 확인을 위해 임의 업무 기록을 생성하지 않는다. 쓰기 요청은 저장 전 대상·입력값을 확인하고 저장 후 같은 대상 상세에서 결과를 대조한다. 저장 응답이 불명확하면 재조회한 뒤 재시도 여부를 결정한다.
