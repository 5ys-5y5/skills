# 내원·접수 검증

허가된 테스트 CRM과 합성 진료 건만 사용한다. 이 문서는 시나리오이며 실행 결과가 아니다.

| 요청·관찰값 | 합격 기준 |
|---|---|
| 오늘 예약 환자의 접수 요청. 같은 진료 건이 이미 접수됨 | 새 접수를 만들지 않고 기존 접수번호·상태를 안내함 |
| 도착 확인만 요청. 도착과 접수는 별도 상태 | 도착만 변경하고 접수로 확대하지 않음 |
| 접수 요청. 대상 진료 건이 종료됨 | 임의로 대기 상태로 되돌리지 않고 처리 불가 사유를 안내함 |

정상 도착 처리 후 같은 진료 건의 상세에서 환자·병원 기준 날짜·저장 상태를 확인한다. 대기시간이 없으면 추측하지 않는다. 결과 기록 방식은 상위 분류 README를 따른다.
